## ตรวจ MAN-28 เมื่อทางรัฐจำลองตอบ HTTP 503

สร้าง Android debug APK ก่อนเริ่มแก้ตัวแทนบริการ ไฟล์รองรับ ARM, ARM64 และ x64 ตรวจ SHA-256 จาก APK ที่ติดตั้งบน Android ได้ค่าเดียวกับไฟล์ส่งมอบ `E7CF1D7155B73CB1ADB15D472F6037141885E6132D4C6D28209EEC4EDC6ABFCF` ไฟล์ `thang-rot-man28-debug.apk` และภาพทดสอบอยู่ในโฟลเดอร์ส่งมอบภายในเครื่อง `app/build/handoff/`

ใช้บัตรจำลองจากทางรัฐ ตรวจล่าสุด 27 พ.ย. 2569 และใช้ได้ถึง 30 พ.ย. 2569 ตัวแทนตอบ HTTP 503 ทั้งตอน 30 พ.ย. เวลา 23:59:59 น. และตอน 1 ธ.ค. เวลา 00:00:00 น. ตามเวลาไทย ผลรีเฟรชไม่เปลี่ยนค่าเดิม วันตรวจ หรือวันหมดอายุ

| หลังรีเฟรชล้มเหลว | ผลที่ตรวจได้ |
| --- | --- |
| ค่าเดิมยังใช้ได้ | Android แสดงยอดประเมิน 800 บาทต่อเดือนและโปรไฟล์ยังแสดงทางรัฐกับวันตรวจเดิม API แชทคัดกรองเบี้ยพื้นฐานได้โดยข้ามคำถามเรื่องบัตร ภาพ `man28-valid-profile.png` |
| ค่าเดิมหมดอายุ | APK แสดงค่าบัตรเก่าพร้อมวันตรวจเดิมและถามเรื่องบัตรเมื่อเช็กเบี้ยความพิการ API เว้นค่าบัตรจากการคัดกรองและถามเฉพาะภาษีหัก ณ ที่จ่ายเมื่อเลือกเช็กคืนภาษี ภาพ `man28-expired-profile.png` และ `man28-expired-chat.png` |

ชุดตรวจ backend ผ่าน 162/162 รวม MAN-28 และ contract regression ผ่าน 245/245 จุดเรียกรีเฟรชอยู่ในตัวทดสอบภายใน server เดโม [ตัวแทน HTTP 503](../../contracts/fixtures/man28-refresh.js) · [เครื่องมือรันกับ Android](../../contracts/run-thang-rot-man28.js) · [เคสตรวจ backend](../../contracts/test-thang-rot-manual.js)

เมื่อตรวจซ้ำ ให้รัน `node contracts/run-thang-rot-man28.js 4392` และตั้ง `adb reverse tcp:8080 tcp:4392` บนเครื่องทดสอบ ใช้ device ID ของ APK เดียวกันส่ง `valid <device-id>` แล้วส่ง `expired <device-id>` ในเทอร์มินัลของตัวทดสอบ เครื่องมือตรวจ 503 และวันตรวจเดิมทุกครั้ง เปิดโปรไฟล์และเริ่มแชทจากหน้าแรกในแต่ละสถานะเพื่อดูผลจากแอป

| บริการ | สิ่งที่ต้องขอจากเจ้าของข้อมูลและตรวจใน sandbox ที่ได้รับอนุญาต | ทางกรอกเองระหว่างรอ |
| --- | --- | --- |
| ThaID | สิทธิ์และตัวอย่างข้อมูลจริงแยกวันเกิด สัญชาติ จังหวัด และเขตตามทะเบียน พร้อมนิยามเขตและวันอ้างอิงที่ใช้ได้ | ถามอายุ สัญชาติ หรือพื้นที่ทะเบียนเฉพาะข้อตามเกณฑ์ ใช้เขตหางานจากโปรไฟล์แยกต่างหาก |
| ทางรัฐ | เจ้าของชุดข้อมูลตามประเภทบัตรหรือสถานะการจ่าย ขอบเขตสิทธิ์รายฟิลด์ และตัวอย่างใช้ได้ ใช้ไม่ได้ ไม่พบแถว พร้อมวันที่มีผลและหมดอายุ | ถามสถานะบัตรหรือการรับเบี้ยเฉพาะรายการที่เลือก |
| ประกันสังคม | หลักฐาน ม.33 เหตุและวันออกจากงาน ความครบทั้งช่วง 15 เดือน พร้อมนิยามสถานะสิ้นสุดผู้ประกันตนและเดือนสะสม ม.33/39 แยกสำหรับชราภาพ | ถามช่วงสมทบและค่าจ้างของเหตุที่ตรวจอยู่ ชราภาพให้ขั้นตอนตรวจต่อกับ สปส. |
| D-MyTax | สิทธิ์เข้าถึงฟิลด์ และตัวอย่างยอดบวก ยอดศูนย์ที่ครบ และผลว่าง แสดงปีภาษี หน่วยบาท และเกณฑ์ความครบที่เจ้าของข้อมูลรับรอง | ถามสถานะหักภาษีของปีนั้น ดูยอดคืนจริงกับกรมสรรพากร |
