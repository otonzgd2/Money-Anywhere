# รายการไอคอน (index.html)

ไอคอนทั้งหมดในแอปเป็น [Lucide](https://lucide.dev/icons/) แล้ว ไม่มี emoji เหลือ ยกเว้นลูกศร → ที่ใช้เป็นตัวคั่นในประโยคแชท

- **ที่มา:** `lucide-static@0.460.0` (license ISC) เก็บเฉพาะไอคอนที่หน้านี้ใช้ ฝังเป็นโค้ดใน `<script id="lucide-icons">` จึงเปิดแบบ offline ได้
- **ใช้ในโค้ด:** `ic('ชื่อไอคอน')` คืนค่า SVG ที่ใช้สีตามตัวอักษรรอบข้าง ใส่สีสถานะได้ด้วย `ic('ชื่อ', 'ok' | 'no' | 'q' | 'mut' | 'big')` ในส่วน HTML ที่ไม่ได้สร้างจาก JavaScript ใช้ `<i data-ic="ชื่อ"></i>` แล้วจะถูกแทนเป็น SVG ตอนโหลดหน้า
- **เพิ่มไอคอนใหม่:** คัดลอกเนื้อใน `<svg>` ของไอคอนจาก lucide.dev มาใส่เพิ่มใน `ICONS` โดยใช้ชื่อเดียวกับบน lucide.dev
