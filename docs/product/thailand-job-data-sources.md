# แหล่งข้อมูลงานและรายได้ในประเทศไทย (บันทึกผลการค้นหา)

**สถานะ:** บันทึกผลการค้นหาออนไลน์ ยังไม่ได้ทดสอบเรียก API จริง และไม่ใช่เอกสารขั้นตอนของ AI-DLC
**ขอบเขต:** เฉพาะประเทศไทย ครอบคลุมแหล่งข้อมูลงานจากภาครัฐและเอกชน และขยายไปถึงโอกาสหารายได้ทั้ง 10 หมวด (ส่วนที่ 7 ถึง 9)
**เอกสารที่เกี่ยวข้อง:** [requirements.md](requirements.md) (สาย B ของ MVP คือการหางาน)
**อัปเดตล่าสุด:** ดูบันทึกการเปลี่ยนแปลงท้ายไฟล์

## สรุปสั้นๆ

ยังไม่พบ API ทางการที่เปิดให้เรียกใช้เพื่อหาตำแหน่งงานว่างในไทย ทั้งจากภาครัฐและเว็บงานเอกชน (คำว่า "ไม่พบ" ไม่ได้แปลว่า "ไม่มี") ก่อนนำข้อมูลในไฟล์นี้ไปใช้ ให้ตรวจกับหน้าทางการอีกครั้ง เพราะราคา โควตา และเงื่อนไขอาจเปลี่ยนได้

## 1. ภาครัฐไทย

| แหล่งข้อมูล | สิ่งที่พบ | ใช้ดึงตำแหน่งงานได้ไหม |
|---|---|---|
| SmartJob กรมการจัดหางาน (https://smartjob.doe.go.th) | เว็บเปลี่ยนเส้นทางไปที่ HTTP จึงเปิดไม่ได้ในเครื่องมือที่ใช้ตรวจ และไม่พบเอกสาร API | ยังไม่พบ API ควรสอบถามกรมการจัดหางานโดยตรง |
| data.go.th (พอร์ทัลข้อมูลเปิดภาครัฐ) | เป็นพอร์ทัลข้อมูลเปิดที่มี API ตามรายการที่ https://apis.io/providers/open-government-thailand/ | ไม่พบชุดข้อมูลตำแหน่งงานว่าง ต้องค้นบนพอร์ทัลด้วยตนเองอีกครั้ง |
| Thailand-Open-APIs (https://github.com/mogohichi/Thailand-Open-APIs) | รายการ API ข้อมูลเปิดของไทยที่ชุมชนรวบรวม | ยังไม่ได้ตรวจว่ามีหมวดงานหรือไม่ |
| ตัวรวมข้อมูลเปิดไทยบน Apify (https://apify.com/subimpact/th-open-data-studio) | เครื่องมือของบุคคลที่สามที่ดึงข้อมูลจาก data.go.th มีชุดข้อมูลแรงงาน | ได้เฉพาะสถิติแรงงาน ไม่ใช่ตำแหน่งงานว่าง |

ข้อมูลภาครัฐที่น่าจะใช้ประโยชน์ได้คือสถิติ เช่น ค่าจ้างและอัตราการว่างงาน (เช่นจากสำนักงานสถิติแห่งชาติ) ไม่ใช่ประกาศรับสมัครงานรายตำแหน่ง

## 2. เว็บงานเอกชนของไทย

| เว็บ | มี API ทางการไหม | ทางเลือกที่พบ |
|---|---|---|
| JobThai | ไม่พบ | scraper ของบุคคลที่สามบน Apify: https://apify.com/asiajobs/jobthai-jobs-scraper , https://apify.com/listingworks/jobthai-scraper/api |
| JobsDB Thailand | ไม่พบ | scraper บน Apify: https://apify.com/blackfalcondata/jobsdb-scraper |
| JobBKK | ไม่พบ | scraper บน Apify: https://apify.com/santamaria-automations/jobbkk-jobs-scraper/api |
| JobTopGun | ไม่พบ | scraper บน Apify: https://apify.com/unfenced-group/jobtopgun-scraper/api/javascript |

**scraper คืออะไร:** โปรแกรมที่เปิดหน้าเว็บแทนคน แล้วคัดลอกข้อมูลมาเก็บเป็นตาราง Apify เป็นแพลตฟอร์มที่คนทั่วไปนำ scraper มาให้เช่าใช้ เว็บงานไม่ได้เป็นผู้เปิดให้

ผลตรวจ robots.txt (อ่านอย่างเดียว) ไฟล์ robots.txt เป็นเพียงคำแนะนำสำหรับบอต ไม่ใช่ข้อกำหนดทางกฎหมาย และยังไม่ได้อ่านข้อกำหนดการใช้งาน (Terms of Use) ของแต่ละเว็บ

| เว็บ | สิ่งที่พบ |
|---|---|
| JobsDB Thailand | ห้ามบอตเข้า `/api/jobsearch/` และ `/graphql` แปลว่า API ค้นหางานภายในไม่เปิดให้คนนอกใช้ |
| JobTopGun | ห้ามบอตเข้า `/api/` |
| JobThai | อนุญาตการเข้าถึงทั่วไป ห้ามเฉพาะบางเส้นทาง เช่น `/resume/` และ `/corporate/` |
| JobBKK | ห้ามเฉพาะบางเส้นทาง เช่น `/resumes/` และ `/jobs/apply/` ไม่ได้ห้ามหน้าค้นหางาน |

หน้าเว็บค้นหางานได้เพราะเรียก API ภายในของเว็บเอง ซึ่งดูได้ที่แท็บ Network (Fetch/XHR) ใน DevTools ของเบราว์เซอร์ แต่ API เหล่านี้ไม่มีเอกสาร และเจ้าของเว็บไม่ได้เปิดให้นักพัฒนาภายนอกใช้

## 3. API ต่างประเทศที่ตรวจว่าครอบคลุมไทยหรือไม่

| บริการ | มี API ทางการ | ครอบคลุมไทยหรือไม่ |
|---|---|---|
| Adzuna (https://developer.adzuna.com/) | มี | ไม่พบประเทศไทยในรายชื่อประเทศที่เจอ (มีสิงคโปร์) จึงใช้กับงานไทยไม่ได้ |
| JSearch โดย OpenWeb Ninja (https://www.openwebninja.com/blog/best-job-data-apis-2026) | มี รวมผลจาก Google for Jobs แผนฟรีประมาณ 200 คำขอต่อเดือน | ยังไม่ยืนยัน ต้องทดลองเรียกด้วยคำค้นภาษาไทย |

### ผลการตรวจเพิ่มเติม

- **JSearch:** พารามิเตอร์ `country` รับรหัสประเทศ ISO 3166-1 และ `language` รับรหัสภาษา ISO 639 ([เอกสาร](https://apify.com/openweb-ninja/jsearch/input-schema)) ดังนั้นการส่ง `country=th` น่าจะรับได้ แต่ไม่มีแหล่งใดยืนยันจำนวนงานไทยที่ได้จริง ต้องทดสอบเรียกด้วย API key ผลหนึ่งหน้า (สูงสุด 10 งาน) นับเป็น 1 คำขอ
- **Fastwork (https://fastwork.co):** ไม่มี API สำหรับนักพัฒนาที่เปิดสาธารณะ ตามโปรไฟล์ที่ https://apis.io/providers/fastwork/ Fastwork เป็นตลาดจ้างฟรีแลนซ์ ตรงกับสาย C ของ MVP ทางที่ทำได้คือขอเป็นพาร์ทเนอร์หรือใช้ลิงก์ไปยังเว็บ
- **ค้นเฉพาะแหล่งของไทยรอบที่สอง:** ได้ผลเป็น scraper ของบุคคลที่สามบน Apify เช่นเดิม ไม่พบ API งานทางการของไทย

## 4. ความเสี่ยง

- scraper บน Apify เขียนโดยบุคคลที่สาม ไม่ใช่บริการที่เว็บงานเปิดให้ ยังไม่ได้อ่านข้อกำหนดการใช้งานของเว็บเหล่านั้น จึงมีความเสี่ยงด้านข้อกำหนด ความเสถียร และความถูกต้องตามกฎหมายของการดึงข้อมูล
- ข้อมูลที่ scrape มาอาจพังเมื่อเว็บเปลี่ยนหน้าตา

## 5. ทางเลือกสำหรับสาย B ของ MVP (การหางาน)

1. ใช้ชุดข้อมูลอ้างอิงขนาดเล็กที่ระบุแหล่งที่มา และติดป้าย DEMO / MOCK ในส่วนที่เป็นข้อมูลจำลอง (สอดคล้องกับส่วนที่ 5 ของ requirements)
2. ทดสอบ JSearch ด้วยคำค้นภาษาไทยเมื่อมี API key
3. ติดต่อกรมการจัดหางานหรือเว็บงานของไทย เพื่อขอเป็นพาร์ทเนอร์หรือขอข้อมูลอย่างเป็นทางการ
4. ให้ผู้ใช้กดลิงก์ไปหน้าค้นหาของเว็บงานโดยตรง แทนการคัดลอกประกาศมาแสดงเอง

## 6. คำถามที่ยังไม่มีคำตอบ

- data.go.th หรือ SmartJob มีข้อมูลตำแหน่งงานว่างให้ดึงหรือไม่
- JSearch ให้ผลงานไทยจริงหรือไม่
- ข้อกำหนดการใช้งานของ JobThai, JobsDB, JobBKK และ JobTopGun ว่าอย่างไรเกี่ยวกับการดึงข้อมูลอัตโนมัติ

## 7. แนวทางตามหมวดโอกาส (10 หมวด)

เขียนจากความรู้ทั่วไป ยังไม่ได้ตรวจว่าหน่วยงานหรือแพลตฟอร์มที่กล่าวถึงมี API หรือไม่ ต้องตรวจก่อนใช้งานจริง

หมวดส่วนใหญ่เป็น **กฎและเงื่อนไข** ไม่ใช่รายการที่ดึงจาก API ได้ทันที แนวทางคือสร้าง **ฐานความรู้ที่คัดเองและมีเวอร์ชัน** (ไฟล์ JSON) โดยแต่ละรายการมีชื่อ เงื่อนไข ลิงก์แหล่งที่มา และวันที่ตรวจล่าสุด ให้ AI ช่วยจับคู่และอธิบาย ส่วนการตัดสินสิทธิ์และการคำนวณตัวเลขให้ใช้กฎที่ทดสอบได้ (ตามส่วนที่ 6 ของ requirements)

| ที่ | หมวด | แหล่งข้อมูลที่น่าจะใช้ | วิธีทำ |
|---|---|---|---|
| 1 | สวัสดิการรัฐ | กระทรวงพัฒนาสังคมฯ, กรมบัญชีกลาง, สำนักงานประกันสังคม | ฐานความรู้ที่คัดเอง และลิงก์ไปหน่วยงาน ห้ามบอกเป็นนัยว่าเข้าถึงข้อมูลสิทธิ์รายบุคคลได้ |
| 2 | เงินคืน (ภาษี มัดจำ) | กรมสรรพากร (ขั้นตอนขอคืนภาษี) | ฐานความรู้ และเช็กลิสต์ การคำนวณใช้กฎที่ทดสอบได้ เรื่องมัดจำเป็นเรื่องระหว่างบุคคล ให้คำแนะนำทั่วไป |
| 3 | เงินที่มีคนค้างจ่าย (ค่าจ้าง ค่าชดเชย) | กรมสวัสดิการและคุ้มครองแรงงาน, ศาลแรงงาน, สำนักงานประกันสังคม | ฐานความรู้ และเช็กลิสต์การร้องเรียน |
| 4 | งานประจำ | เว็บงานเอกชน, SmartJob | ยังไม่พบ API ให้ทดสอบ JSearch ขอเป็นพาร์ทเนอร์ หรือใช้ลิงก์ |
| 5 | งานพาร์ทไทม์/รายวัน | เว็บงานเอกชน และแพลตฟอร์มงานรายวัน | เหมือนหมวด 4 |
| 6 | ฟรีแลนซ์ | Fastwork และแพลตฟอร์มอื่น | Fastwork ไม่มี API สาธารณะ ใช้ลิงก์หรือขอเป็นพาร์ทเนอร์ |
| 7 | ขายของมือสอง | ตลาดออนไลน์ เช่น Shopee, Lazada, Kaidee, Facebook Marketplace | API (ถ้ามี) มักไว้จัดการร้านของผู้ขายเอง ไม่ใช่ค้นหาประกาศ ให้แค่คำแนะนำและลิงก์ |
| 8 | รายได้จากทรัพย์สินที่มี | ความรู้ทั่วไป | AI เสนอไอเดียพร้อมสมมติฐานและต้นทุนที่ระบุชัด เป็นการประมาณเท่านั้น |
| 9 | ทุนช่วยเหลือที่ไม่ต้องคืน | เว็บของหน่วยงานที่ให้ทุน | ฐานความรู้ที่คัดเอง ทุกรายการต้องมีวันปิดรับสมัครและต้องตรวจซ้ำบ่อย |
| 10 | รายได้จากทักษะ | ข้อมูลค่าตอบแทนในตลาด | AI วิเคราะห์ร่วมกับข้อมูลเทียบเคียง ระบุว่าเป็นประมาณการ |

การแบ่งสายของ MVP: สาย A คือหมวด 1, 2, 3, 9 สาย B คือหมวด 4, 5, 6 สาย C คือหมวด 7, 8, 10

## 8. ตัวกรอง: แหล่งข้อมูลที่ใช้เป็นสาธารณะได้

คำว่า "ใช้เป็นสาธารณะได้" ในที่นี้หมายถึง นำไปใช้ในผลิตภัณฑ์ที่แสดงต่อสาธารณะ เช่นการแข่งขัน ได้อย่างปลอดภัย โดยเจ้าของแหล่งข้อมูลอนุญาตการใช้แบบนั้น หรือเป็นข้อมูลสาธารณะอย่างเป็นทางการที่มีแหล่งที่มาชัดเจน

| ประเภทแหล่งข้อมูล | ใช้เป็นสาธารณะได้ไหม | เหตุผล |
|---|---|---|
| หน้าเว็บหน่วยงานทางการที่ใช้อ้างอิง (ลิงก์ และสรุปด้วยคำของเราเอง) | ใช้ได้ | เป็นข้อมูลสาธารณะที่มีแหล่งที่มาชัดเจน ต้องสรุป ใส่ลิงก์ และแสดงวันที่ตรวจ |
| ข้อมูลเปิดภาครัฐที่ระบุสัญญาอนุญาต (ชุดข้อมูลบน data.go.th) | ใช้ได้หลังตรวจสัญญาอนุญาต | สัญญาอนุญาตระบุแยกตามชุดข้อมูล |
| API ทางการที่ใช้ key ภายใต้ข้อกำหนด (เช่น JSearch) | ใช้ได้หลังอ่านข้อกำหนด | ต้องตรวจสิทธิ์การใช้เชิงพาณิชย์และการแสดงผล |
| ลิงก์ไปหน้าค้นหาของเว็บงาน | ใช้ได้ | ไม่มีการคัดลอกข้อมูล |
| scraper บน Apify ของ JobThai, JobsDB, JobBKK, JobTopGun | ไม่แนะนำ | เว็บไม่ได้เปิดให้ JobsDB และ JobTopGun ห้ามเส้นทาง API ใน robots.txt และยังไม่ได้อ่านข้อกำหนด |
| เรียก API ภายในของเว็บที่เห็นใน DevTools | ไม่แนะนำ | ไม่มีเอกสาร และไม่ได้เปิดให้นักพัฒนาภายนอก ควรขออนุญาตเป็นลายลักษณ์อักษรก่อน |
| Adzuna สำหรับงานไทย | ใช้ไม่ได้ | ไม่พบประเทศไทยในรายชื่อประเทศ |
| ข้อมูลจาก Fastwork | ไม่มีให้ใช้ | ไม่มี API สาธารณะ ใช้ลิงก์หรือขอเป็นพาร์ทเนอร์ |
| ข้อมูลสิทธิ์รายบุคคลหรือบันทึกส่วนตัวของรัฐ | อยู่นอกขอบเขต | ส่วนที่ 6 และ 9 ของ requirements |
| โปรไฟล์สมมติและข้อมูลจำลอง | ใช้ได้เมื่อติดป้าย DEMO / MOCK | ส่วนที่ 6 ของ requirements |

เก็บเฉพาะผลที่กรองแล้วไว้ในฐานความรู้ และห้ามเก็บรหัสผ่านหรือข้อมูลส่วนบุคคลที่อ่อนไหว

## 9. การทำให้ข้อมูลเป็นปัจจุบัน

ข้อมูลแต่ละประเภทเก่าเร็วไม่เท่ากัน จึงควรกำหนดรอบการอัปเดตตามประเภท

| ประเภทข้อมูล | ตัวอย่าง | รอบอัปเดตที่เสนอ | วิธีทำ |
|---|---|---|---|
| กฎและเงื่อนไข | เงื่อนไขสวัสดิการ ขั้นตอนขอคืนภาษี | ทุก 3 เดือน และเมื่อมีการเปลี่ยนกฎหมายหรือประกาศ | คนตรวจหน้าเว็บต้นทางอีกครั้ง แล้วอัปเดต `last_verified` |

ฟิลด์ที่เสนอให้มีในแต่ละรายการ (ต้องตัดสินใจจริงในขั้นออกแบบของ AI-DLC):
- `source_url`, `source_owner` (ลิงก์และเจ้าของแหล่งข้อมูล)
- `last_verified` (วันที่ตรวจล่าสุด), `verified_by` (ผู้ตรวจ)
- `valid_until` หรือ `deadline` (วันหมดอายุหรือวันปิดรับ)
- `status`: ปัจจุบัน, เก่า, หมดอายุ หรือขัดแย้งกับแหล่งอื่น
- `version` (เวอร์ชัน)

ขั้นตอนที่เสนอ:
1. แสดงวันที่ตรวจล่าสุดทุกรายการ และทำเครื่องหมาย "ข้อมูลเก่า" เมื่อเกินรอบอัปเดต พร้อมแจ้งผู้ใช้ (ตาม FR-08 ของ requirements)
2. ตั้งงานตรวจลิงก์เป็นประจำ (เช่นทุกสัปดาห์) เพื่อหาลิงก์เสียหรือถูกเปลี่ยนเส้นทาง แล้วส่งให้คนตรวจต่อ
3. เก็บบันทึกการเปลี่ยนแปลงไว้ใน version control เพื่อย้อนดูได้ว่าแก้อะไรใน commit ไหน
4. กำหนดผู้รับผิดชอบรายหมวด จากสมาชิกทีม 3 คน
5. เมื่อ API ล้มเหลวหรือไม่มีผลลัพธ์ ให้แจ้งตรงๆ ห้ามแต่งข้อมูล (FR-08 และ AC-04)
6. ห้ามเผยแพร่บทสรุปที่ AI เขียนจากแหล่งข้อมูลโดยอัตโนมัติ ให้คนตรวจเทียบกับต้นทางก่อน

ประเด็นที่ต้องถามเจ้าของโครงการ: ใครรับผิดชอบการอัปเดตหลังจบการแข่งขัน เพราะเกี่ยวกับค่าใช้จ่ายและขอบเขตงาน

## บันทึกการเปลี่ยนแปลง

- ฉบับแรก: ภาครัฐไทย เว็บงานเอกชน และ API ต่างประเทศ
- ผลตรวจเพิ่มเติม: JSearch, Fastwork และการค้นเฉพาะไทยรอบที่สอง
- อัปเดต: ผล robots.txt (ส่วนที่ 2), แนวทางรายหมวด (ส่วนที่ 7), ตัวกรองแหล่งข้อมูลที่ใช้สาธารณะได้ (ส่วนที่ 8), แผนอัปเดตข้อมูล (ส่วนที่ 9)
- อัปเดต: แปลเป็นภาษาไทยและปรับให้อ่านง่าย เนื้อหาไม่เปลี่ยน
