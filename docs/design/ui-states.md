# UI states: what shows when, and what changes it

ฉบับที่ใช้กับแอป Flutter (`app/lib/`) ตั้งแต่ 26 พ.ย. 2569 รวมจาก `navigation.md`, mock (`docs/mockups/index.html`), `contracts/app-config.sample.json` และสิ่งที่ Owner ตัดสินแล้ว ถ้าเอกสารอื่นขัดกับไฟล์นี้ ให้ยึดไฟล์นี้ แล้วแก้เอกสารนั้นตามตาราง §8

คำศัพท์:
- **ผู้ใช้ใหม่** = ยังไม่มีความยินยอม ไม่มีคำตอบที่บันทึก ไม่มีแผน และยังไม่เริ่มแชท
- **ผู้ใช้เดิม** = มีคำตอบที่บันทึก หรือมีแผน หรือพิมพ์คุยกับ AI แล้ว (`started` ใน `home_tab.dart`) ความยินยอมอย่างเดียวไม่นับ
- **แผน** = task ใน `GET /v1/tasks` สถานะ `active | blocked | snoozed | finished`

## 1. แถบเมนูล่าง (4 แท็บ)

| ลำดับ | แท็บ | หน้าที่ | ไฟล์ |
|---|---|---|---|
| 1 | 🏠 หน้าแรก | ทำอะไรต่อ | `home_tab.dart` |
| 2 | ✨ โอกาส | หาอะไรได้บ้าง | `opp_tab.dart` |
| 3 | 📋 แผนของฉัน | ที่บันทึกไว้และกำลังทำ | `plans_tab.dart` |
| 4 | 👤 ฉัน | ตั้งค่า ความยินยอม ข้อมูลของฉัน ช่วยเหลือ | `me_tab.dart` |

- **แสดงเมื่อ:** อยู่ที่หน้าหลักของแท็บใดแท็บหนึ่ง ตั้งแต่เปิดแอปครั้งแรก (ผู้ใช้ใหม่ก็เห็น เพื่อเข้า ฉัน และ โอกาส ได้โดยไม่ต้องยินยอม)
- **ซ่อนเมื่อ:** เปิดหน้าเต็มจอทับ ได้แก่ เช็คเงินเอง, แชท AI, เส้นทางรับเงิน, รายละเอียดแผน, รายละเอียดโอกาส กดย้อนกลับแล้วแถบกลับมา
- **กดแท็บ:** สลับแท็บและโหลดข้อมูลแท็บนั้นใหม่ทุกครั้ง
- **ปุ่มย้อนกลับของ Android:** อยู่แท็บอื่นให้กลับหน้าแรกก่อน อยู่หน้าแรกแล้วจึงออกจากแอป

## 3. หน้าแรก: อะไรขึ้นเมื่อไหร่ (เรียงบนลงล่าง)

| สถานะ | การ์ดที่เห็น |
|---|---|
| ผู้ใช้ใหม่ (S1) | ป้าย DEMO / MOCK → "เงินฉันอยู่ไหน?" → **ปุ่ม AI ใหญ่** "ให้ AI หาเงินให้ฉัน" พร้อมข้อความยินยอมและลิงก์ "อ่านประกาศ" → การ์ด "💰 เช็คเงินที่ควรได้ เอง" → การ์ดเล็ก "🔎 หางาน" / "🍳 รายได้จากทักษะ" → ข้อความไม่รับประกัน |
| ผู้ใช้เดิม ยังไม่มีแผน | "เงินของฉัน" → สรุปยอด (ถ้ามีคำตอบ: ต่อเดือน/ครั้งเดียว, "ประมาณจากเกณฑ์ ยังไม่ยืนยัน", "อีก N รายการต้องเช็ค") → **"สิ่งแรกที่ควรทำ"** = เงินอันดับแรกที่ยังไม่อยู่ในแผน (ปุ่ม "ดูวิธีไปรับเงิน") → ปุ่ม AI ("คุยกับ AI ต่อ" ถ้าเคยคุย) → "ตอบเพิ่มอีก N เรื่อง" (เฉพาะเมื่อยังมีข้อค้าง) → "✨ ดูงานและรายได้จากทักษะ" |
| มีแผนที่ยังไม่จบ | สรุปยอด → **"ขั้นต่อไปของคุณ"** (ชื่อแผน, "ขั้นที่ x จาก y: …", ปุ่ม ทำต่อ → S8, ไว้ทีหลัง → P4) → "งานอื่นที่ทำอยู่ N รายการ ›" (เฉพาะ N > 0) → ปุ่ม AI → "ตอบเพิ่ม…" (ถ้ามีข้อค้าง) → ลิงก์โอกาส |
| แผนทั้งหมดจบแล้ว | สรุปยอด → "สิ่งแรกที่ควรทำ" ถ้ายังมีเงินที่ไม่อยู่ในแผน ไม่งั้น "🎉 ไม่มีงานค้าง" → ปุ่ม AI → … |
| ต่อ server ไม่ได้ | การ์ดแดง "📡 ต่อ server ไม่ได้" ด้านบนสุด พร้อมวิธีแก้ (USB / Wi-Fi), ปุ่ม ลองใหม่ และ เปลี่ยนที่อยู่ server |

กฎ "ขั้นต่อไป": แผน `active` ก่อน แล้ว `snoozed` แล้ว `blocked` แผน `finished` ไม่ขึ้น (`nextTask()` มีเทสต์)
การ์ดเช็คเงินเอง (ไม่ใช้ AI) มีให้กดเสมอ: ยังไม่มีคำตอบ = "เช็คเงินที่ควรได้ เอง"; มีข้อค้าง = "ตอบเพิ่มอีก N เรื่อง" (ถามเฉพาะข้อที่ยังไม่ตอบ); ตอบครบ = "แก้คำตอบของฉันเอง" (ถามใหม่ทุกข้อ คำตอบใหม่แทนของเดิม)
หน้าแรกแบบผู้ใช้เดิมเริ่มเมื่อมีคำตอบ แผน หรือพิมพ์คุยกับ AI อย่างน้อย 1 ข้อความ แค่กดปุ่ม AI แล้วออกยังเป็นแบบผู้ใช้ใหม่ ปุ่มเปลี่ยนเป็น "คุยกับ AI ต่อ" เฉพาะเมื่อพิมพ์คุยแล้ว

## 4. ความยินยอม (PDPA)

| จุด | ถามอย่างไร |
|---|---|
| เปิดแอป / ดูโอกาส / เช็คเงินเอง (preview) | ไม่ถาม เพราะไม่บันทึกอะไร |
| กดปุ่ม AI ใหญ่ | ไม่มีหน้าต่าง ข้อความบนปุ่มคือความยินยอม: บันทึก core + ai (คงค่าอื่นที่เคยให้ไว้) |
| เปิดเส้นทางรับเงิน, บันทึกเป็นแผน, บันทึกโอกาส, ตอบ "ยื่นแล้ว/สนใจ" | **P1 แผ่นความยินยอม** ครั้งแรกเท่านั้น: core (บังคับ), AI (ปิดไว้ก่อน), เตือนงานค้าง (ปิดไว้ก่อน), ติ๊ก "อายุ 20 ปีขึ้นไป" ก่อนกดได้, ลิงก์ประกาศ ปุ่ม "ยอมรับและไปต่อ" / "ไม่ใช่ตอนนี้" (ไม่ยอม = ไม่บันทึกอะไร และกลับหน้าเดิม) |
| แท็บ ฉัน | เปิด/ปิด AI, เตือนงานค้าง, ตำแหน่ง มีผลทันที ถอน AI = ล้างแชทและสิ่งที่ AI จำ ถอน core ได้ทางเดียวคือ "ลบข้อมูลทั้งหมด" |

เส้นทางรับเงินถามความยินยอมก่อนเปิด (ต่างจาก mock ที่ถามตอนกดบันทึก) เพราะ API คิดเส้นทางจากคำตอบที่บันทึกแล้ว (`GET /v1/money/{id}`)

## 5. ข้อมูลรีเฟรชเมื่อไหร่

- ทุกการกระทำที่เปลี่ยนข้อมูล (ตอบคำถาม, ยินยอม/ถอน, สร้าง/อัปเดต/ลบแผน, ติ๊กเอกสาร, ลบข้อมูล, โหลดผู้ใช้ตัวอย่าง) เรียก `AppState.bump()` ทุกแท็บที่ฟังอยู่โหลดใหม่
- ปิดหน้าเต็มจอ (S3, S4, S5, S8) แล้วกลับมา = โหลดใหม่
- กดแท็บ = โหลดใหม่; ดึงลง (pull to refresh) ได้ทุกแท็บ
- แชทอยู่ใน `ChatSession` ที่แอปถือไว้: กดย้อนกลับแล้วเข้าใหม่ แชทเดิมยังอยู่ ถ้า server ลืมการคุย (รีสตาร์ต) เริ่มใหม่เอง โดยไม่ถามข้อที่ตอบแล้ว

## 6. Popup / แผ่นล่าง / ข้อความแจ้ง

| id | เกิดเมื่อ | ปุ่ม |
|---|---|---|
| P1 | แผ่นความยินยอม (ดู §4) | ยอมรับและไปต่อ / ไม่ใช่ตอนนี้ |
| P2 | "อ่านประกาศ" (ปุ่ม AI, P1, ฉัน) | ปิด |
| P3 | ใน S8 กด "😟 ติดปัญหา" | ไม่เข้าใจขั้นตอน / เอกสารไม่ครบ / เว็บใช้ไม่ได้ / อื่นๆ → `block` |
| P4 | "ไว้ทีหลัง" (หน้าแรก, S8) | พรุ่งนี้เช้า / อีก 3 วัน / สัปดาห์หน้า / ไม่ต้องเตือน → `snooze`, แจ้ง "ตกลง: …" |
| P5 | ใน S8 แผนจบแล้ว กด "แจ้งผล" | ได้รับแล้ว / ยังไม่ได้รับ / ไม่ผ่าน / อื่นๆ → `report_outcome` (ผู้ใช้แจ้ง) |
| P6 | **กลับเข้าแอปหลังเปิดลิงก์ทางการ** (ปุ่ม "เปิด ↗" ใน S5, "ดูประกาศต้นทาง ↗" ใน S6b) ถามครั้งเดียวต่อการเปิด | ไม่ต้องบันทึก / ยังไม่ได้ยื่น แต่สนใจ (สร้างแผน) / ✓ ยื่น/สมัครแล้ว (สร้างแผน + ทำขั้นถึง "ยื่น" ตามที่ผู้ใช้แจ้ง) |
| P7 | ฉัน > ลบข้อมูลทั้งหมด | ยกเลิก / ลบข้อมูล → กลับ S1, แจ้ง "ลบข้อมูลและถอนความยินยอมแล้ว" |
| P8 | S8 ไอคอนถังขยะ | ยกเลิก / ลบ |
| P9 | ฉัน > ดูข้อมูลที่เก็บไว้, วิธีใช้, รู้ทันมิจฉาชีพ, ที่อยู่ server | ปิด / บันทึก |
| P10 | S6b รายงานประกาศ | น่าสงสัย / ข้อมูลผิด / ปิดรับแล้ว / อื่นๆ → แจ้ง "ขอบคุณ ส่งรายงานแล้ว" |
| แจ้งพร้อม "เลิกทำ" | S8 "✓ ทำขั้นนี้เสร็จแล้ว" แสดง 5 วินาที | เลิกทำ → `undo` |
| ยืนยันในแชท | AI เสนอการกระทำที่เปลี่ยนข้อมูล | ยืนยัน / ไม่ใช่ (ไม่มีอะไรเปลี่ยนจนกว่าจะกดยืนยัน) |
