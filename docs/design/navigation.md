# โครงเมนูและลำดับความสำคัญของหน้าจอ (ร่าง)

หลัก: ฟีเจอร์ครบได้ แต่สิ่งที่เห็นทันทีต้องน้อย ผู้ใช้หลักรวมผู้สูงอายุ จึงให้ 1 หน้ามีการกระทำหลัก 1 อย่าง ที่เหลือซ่อนไว้ชั้นที่สอง

## เมนูหลัก (แถบล่าง 4 แท็บ)
| แท็บ | หน้าที่เดียว | สิ่งที่ย้ายมาอยู่ข้างใน |
|---|---|---|
| 🏠 หน้าแรก | "ทำอะไรต่อ" | การ์ดขั้นต่อไป, ลิงก์งานอื่น, ลิงก์โอกาสใหม่, ลิงก์คุยกับ AI |
| ✨ โอกาส | "หาอะไรได้บ้าง" | รายการ ↔ แผนที่ (ปุ่มลอยปุ่มเดียว), ค้นหา, ตัวกรอง, แผนรายได้ |
| 📋 แผนของฉัน | "ที่บันทึกไว้และกำลังทำ" | ความคืบหน้า, เช็คลิสต์, อัปเดตสถานะ |
| 👤 ฉัน | "ตั้งค่าและช่วยเหลือ" | โปรไฟล์, ทักษะ, ตัวอักษรใหญ่, การเตือน, ข้อมูลของฉัน/ลบข้อมูล, แหล่งข้อมูล, วิธีใช้, รู้ทันมิจฉาชีพ |

เหตุผลที่ 4 แท็บ: แนวทางทั่วไปของแอปมือถือคือ 3-5 แท็บ ตั้งค่าเป็นแท็บที่มีชื่อชัดเจนหาง่ายกว่ารูปโปรไฟล์มุมจอสำหรับผู้สูงอายุ การบันทึกไว้รวมกับความคืบหน้าในแท็บเดียวแทนที่จะแยกแท็บ "รายการโปรด"

## หน้าโอกาส: เห็นทันทีเท่านี้
1. ช่องค้นหา + ปุ่ม "⚙️ ตัวกรอง" (มีตัวเลขบอกจำนวนตัวกรองที่เปิด)
2. ชิปหมวด 5 อัน เลือกได้ทีละอัน: ทั้งหมด, งาน, ทักษะ, ขายของ, เงิน/สิทธิ์
3. ผลลัพธ์ (รายการหรือแผนที่)
4. ปุ่มลอยสลับ "ดูแผนที่ / ดูรายการ"

ย้ายเข้า "ตัวกรอง": ระยะทาง, เรียงตาม, เฉพาะที่ระบุเงิน, แสดงประกาศน่าสงสัย, แหล่งข้อมูล
บนแผนที่เหลือ: ＋ / － / 📍 และป้ายตำแหน่งค้นหา (กดเพื่อเปลี่ยนเขต)

## ที่ตัดออกจากระดับแรก
| เดิม | ไปอยู่ที่ |
|---|---|
| ชิปบนแผนที่ 8 อัน | ชิปหมวด 5 อัน + ตัวกรอง |
| แถบรัศมี 1/3/5/10 | ตัวกรอง และปุ่ม ＋ / － |
| ปุ่มสลับรายการ/แผนที่ด้านบน | ปุ่มลอยด้านล่าง |
| ปุ่ม A+ และแถบโปรไฟล์บนหน้าแรก | แท็บ ฉัน |
| ปุ่มคุยกับ AI + เลือกเองบนหน้าแรก | ลิงก์เดียว "คุยกับ AI" (เลือกเองอยู่ในแท็บ ฉัน > แก้ไขโปรไฟล์) |
| ชิปแหล่งข้อมูล | ตัวกรอง และแท็บ ฉัน |

## ข้อควรตรวจเมื่อทำของจริง
- ทดสอบกับผู้ใช้จริงอย่างน้อย 3 คน (รวมผู้สูงอายุ) ว่าหางานค้างและเปลี่ยนตัวอักษรได้เองโดยไม่ต้องบอก (สมมติฐาน ยังไม่ได้ทดสอบ)
- ขนาดเป้ากดอย่างน้อย 48 dp ตามแนวทาง Material
