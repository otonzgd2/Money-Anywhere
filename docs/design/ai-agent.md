# ผู้ช่วย AI (agent): เข้าถึงอะไร จำอะไร ทำอะไรได้

สัญญา: `POST /v1/ai/conversations`, `.../{id}/messages`, `.../{id}/actions/{actionId}`, `GET/POST/DELETE /v1/me/memory`
โค้ด: `contracts/adapters/agent.js` (rules + OpenAI-compatible tool calling), เครื่องมืออยู่ใน `agentTools()` ของ `contracts/mock-server.js`

## หลัก
- AI ไม่ได้จำผู้ใช้เอง ทุกครั้ง server ส่งข้อมูลของผู้ใช้คนนั้นผ่าน **เครื่องมือ** เท่านั้น ไม่เห็นผู้ใช้คนอื่น
- ต้องยินยอมข้อ `ai` ก่อน ไม่ยินยอมได้ 403 และฟีเจอร์อื่นยังใช้ได้ด้วยกฎ

## เครื่องมือ
| เครื่องมือ | โหมด | ทำอะไร |
|---|---|---|
| get_money_overview | อ่าน | เงินที่อาจได้ และสถานะแต่ละรายการ |
| get_money_route | อ่าน | ขั้นตอนรับเงินของรายการหนึ่ง |
| search_opportunities | อ่าน | ค้นหาโอกาสใกล้ผู้ใช้ (ส่งกลับไม่เกิน 5) |
| list_tasks | อ่าน | งานในแผน |
| get_profile | อ่าน | โปรไฟล์ **ไม่มีชื่อ** |
| create_task, snooze_task, complete_step, update_facts | ต้องยืนยัน | กลายเป็นปุ่ม "ยืนยัน / ไม่ใช่" ให้ผู้ใช้กด แล้วรันผ่าน service เดียวกับ API ปกติ |
| remember | จำ | บันทึกสั้นๆ ที่ผู้ใช้เห็นและลบได้ |
| อย่างอื่นทั้งหมด | ปฏิเสธ | ลบข้อมูล, เปลี่ยนความยินยอม, ส่งอะไรออกนอกแอป, ยื่นแทน ทำไม่ได้ |

## กติกา (ทดสอบแล้วใน `test-contract.js`)
1. ตัวเลขเงินในคำตอบต้องมีอยู่ในผลของเครื่องมือ ไม่งั้นถูกแทนด้วย "(ดูยอดในแอป)" (ทดสอบ: LLM จำลองแต่ง 9,999 บาท ถูกตัด, 600 บาทจากเครื่องมือยังอยู่)
2. เครื่องมือเขียนไม่ทำจนกว่าผู้ใช้ยืนยัน (ทดสอบ: งานไม่เพิ่มจนกด confirm)
3. เครื่องมือที่ไม่อยู่ในรายการถูกเพิกเฉย (ทดสอบ: `delete_everything`)
4. สูงสุด 4 รอบต่อคำถาม หมดเวลา 10 วินาที ล้มแล้วใช้ rules agent
5. ถอนความยินยอม ai: ลบสิ่งที่ AI จำ (source = ai) และล้างการคุยทันที
6. ประวัติแชทเก็บแค่ในการคุยนั้น ไม่อยู่ใน export ไม่ใช้ข้ามการคุย สิ่งที่ใช้ข้ามการคุยคือ memory ที่ผู้ใช้เห็นเท่านั้น

## ระดับที่ทำ
- ระดับ 2 (ผู้ช่วยที่รู้จักผู้ใช้) และระดับ 3 บางส่วน (ทำในแอปได้เมื่อยืนยัน)
- ไม่ทำระดับ 4 (ทำแทนนอกแอป) ตาม requirements

## ยังไม่ได้ทำ
- ทดสอบกับผู้ให้บริการ AI จริง (ต้องมี key)
- จำกัดจำนวนครั้งต่อวันเพื่อคุมค่าใช้จ่าย (B4 ใน backend-gaps)
- ตรวจคุณภาพคำตอบภาษาไทยกับผู้ใช้จริง
