# Backend Gap Analysis (อัปเดตหลัง API v0.3)

เทียบหลังบ้านกับ `docs/product/requirements.md` และสิ่งที่ backend ต้องมีเพื่อใช้งานจริง
ระดับ: **P0** = ไม่มีแล้วผ่าน AC/Demo ไม่ได้, **P1** = ต้องมีก่อนให้คนอื่นใช้นอกเครื่องทีม, **P2** = ทำทีหลังได้
ผลทดสอบล่าสุด: `npm test` ใน `contracts/` 87/87 PASS, 47/47 operations · `docs/mockups/smoke-test.js` 53/53 PASS
