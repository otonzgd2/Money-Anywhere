# ประเมิน Demo ตามเกณฑ์ AI Skill Wars

**คะแนนประเมินความพร้อม 58/100 ก่อนบทลงโทษ** จากหลักฐานที่มี ณ commit ใน [ฐานอ้างอิง](README.md) คะแนนในตารางเป็นการประเมินของทีมเพื่อจัดลำดับงาน ใช้คะแนนรายข้อของ Booklet หน้า 10–14 ให้คะแนนบางส่วนเมื่อเห็นโค้ดหรือผลทดสอบแต่ยังขาดหลักฐานวันแข่ง และให้ 0 เมื่อสิ่งส่งมอบยังไม่ปรากฏ คะแนนจริงขึ้นกับกรรมการ โจทย์ที่ขยายหน้างาน และการรันจริง

ใช้แผนปิดช่องว่างเพื่อติดตามงาน เจ้าของ และหลักฐานที่ต้องเก็บก่อนกลับไปปรับ Dev Spec กับชุดไฟล์วันแข่ง [เปิดแผนปิดช่องว่างคะแนน](https://github.com/otonzgd2/Money-Anywhere/blob/main/docs/competition/skillwar/gap-closure-plan.md)

## หลักฐานและข้อที่พบ

- API config, OpenAPI และ contract tests ผ่าน ชุด guard 132 เคสและ manual 33 เคสผ่านบน Node 24.22.1 รวมผิดพลาดของ provider, การถอน consent, duplicate answer และ `MAN-28` ซึ่งจำลอง upstream 503
- `flutter test` ผ่าน 80 เคสและ `flutter analyze` ผ่านบน Flutter 3.50.1 และ Dart 3.14.0 สร้าง debug APK ได้หลังใช้วิธีแก้ Kotlin ใน [คู่มือวันงาน](event-runbook.md) รอบนี้ไม่มี Android device หรือ AVD ให้ติดตั้งและตรวจ flow จริงกับ TalkBack
- HTML mockup smoke tests ผ่าน 195/195 และ 37/37. เก็บผลนี้เป็นหลักฐานของ HTML จอจำลอง
- `node tools/gov-data-demo.js` ล้มที่ `A skipped question was repeated` ตรวจและใช้คำขอเทียบเท่าแอปตาม [dev spec](dev-spec.md) ก่อนนำ helper นี้มานับเป็นหลักฐาน
- ทดสอบโมเดลที่ตั้งไว้ของโปรเจกต์ด้วยอินพุตสังเคราะห์ผ่าน HTTP แบบ memory. เคสทำอาหารที่บ้านตอบ `fallback_rules` โดยไม่มี tool call ออกมา ส่วนเคสพิมพ์เอกสารช่วงเช้ากับ “ดูงานอื่น” ตอบ `ok` และมี `search_opportunities` ทั้งสองเทิร์นแต่ไม่พบงาน คำตอบเทิร์นแรกสัญญาว่าจะแจ้งงานใหม่โดยไม่มี action ยืนยัน ต้องกรองข้อความสัญญาเกินขีดความสามารถ และทดสอบเคสที่หาเจอจนบันทึกบน Android
- เวลาใช้งานบนเวที Kiro Activity Log ประจำวันแข่ง และไฟล์ส่งงานครบชุดยังต้องเก็บเพิ่ม ดู [คู่มือวันงาน](event-runbook.md)

หน้า 17 ระบุการตัดสิทธิ์เมื่อไม่มี Kiro Log หรือ log ไม่แสดงการใช้พัฒนา ใช้ fabricated output โดยไม่ระบุ ไม่มี core flow ที่ใช้ได้และโยงปัญหาเมือง หรือ AI แยกจาก flow หลัก หน้า 6, 10 และ 17 ยังระบุว่า fabricated outcome ที่ไม่เปิดเผยได้ 0 ทั้งหมวด 1 อีกสามเงื่อนไขคือใช้ Backup Video หัก 5 คะแนนหมวด 1, crash ใน Q&A แล้วกู้ไม่ได้ให้ข้อ 1.2 ไม่เกิน 3 คะแนน และเด็คเกิน 8 หน้า content หัก 2 คะแนนข้อ 5.4
