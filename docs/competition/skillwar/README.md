# ชุดเตรียมแข่ง AI Skill Wars ของทางรอด

ทางรอด (Money Anywhere) ช่วยคนกรุงเทพฯ ประเมินสิทธิและคัดโอกาสหารายได้ตามพื้นที่ ทักษะ และเวลาที่มี จากนั้นบันทึกเป็นแผนลงมือทำ ชุดนี้จัดทำก่อนแข่งเพื่อประเมิน Demo และใช้เป็นข้อมูลตั้งต้นเมื่อสร้างผลงานด้วย Kiro ในวันงาน

| [Requirements](requirements.md) | นิยามขอบเขต Persona และเงื่อนไขตรวจรับ |
